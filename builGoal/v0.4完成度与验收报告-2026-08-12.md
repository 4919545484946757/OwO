## 5. 开放问题建议默认

- 聊天类白名单首批：QQ / 微信 / 飞书（已在 `whitelist.rs` 默认清单）；授权粒度为**单会话级**（`chat_authorized` 逐会话开启），消息内容默认掩码，发送动作预览 + 审批。
- `.owskill` 分享：权限仅允许白名单集合，敏感度必填，zip-slip 拒绝（已实现并测试）。
- 自动更新：静态 `latest.json` + 签名验证已就绪，托管到任意静态服务器并替换 `plugins.updater.endpoints` 即可启用。

## 6. 运行入口

```powershell
cd agent-sdk
cargo run -p owo-agent-cli -- serve --port 4096 --workspace .   # 核心服务（浏览器打开 http://127.0.0.1:4096/）
cargo run -p owo-agent-cli -- tui --workspace .                 # TUI
scripts\package-desktop.ps1 -Configuration release              # 便携包
scripts\build-installer.ps1                                     # NSIS 安装包
scripts\download-stt-model.ps1                                  # SenseVoice 模型
```
