# browser

用途：打开页面、点击/填表、截图、DOM 快照与网页端到端测试。

## 工作流

1. 确认目标 URL 与任务（导航/填表/截图/测试）。
2. 驱动浏览器执行动作，逐步断言页面状态。
3. 截图或导出 DOM 快照作为证据。
4. 输出结果与失败原因。

## 触发条件

- 用户要求"打开网页、填表单、抓页面、截图、网页自动化测试"。
- 用户要求验证本地 Web 服务的页面行为。

## 权限

- `network:fetch`：仅目标域名。
- `browser:control`：浏览器自动化控制，需用户确认。
