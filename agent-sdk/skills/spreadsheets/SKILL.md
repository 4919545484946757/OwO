# spreadsheets

用途：创建表格、公式/透视计算、数据清洗与校验，输出 `.xlsx` 或 `.csv`。

## 工作流

1. 明确输入数据与期望输出（表头、列、行、公式）。
2. 生成或编辑表格文件，保留公式与格式。
3. 用断言校验数值、行列数与公式结果。
4. 输出文件路径与结果摘要。

## 触发条件

- 用户要求"做表格、统计、透视、转 CSV/xlsx"。
- 用户要求分析或清洗表格数据。

## 权限

- `files:read` / `files:write`：仅工作区内的表格文件。
