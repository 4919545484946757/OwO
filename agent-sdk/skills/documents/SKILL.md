# documents

用途：生成/修改 `.docx`、Word 兼容文档，批注与审阅，产出前必须渲染校验版式。

## 工作流

1. 读取用户给的输入（文本、大纲、现有文件路径）。
2. 用文档模板生成或编辑 `.docx`，保留段落/标题/列表/表格结构。
3. 渲染为页面图像做视觉 QA，检查溢出、断行、分页问题。
4. 输出文件路径与修改摘要。

## 触发条件

- 用户要求"写/改 Word 文档、合同、报告、简历"。
- 用户要求对 `.docx` 文件做批注或审阅。

## 权限

- `files:read` / `files:write`：仅工作区内的文档文件。
