# pdf

用途：从文本/Markdown/HTML 生成 PDF，读取既有 PDF 内容，填写 AcroForm，渲染校验版式。

## 工作流

1. 明确输入（文件路径、模板、表单字段）。
2. 生成或修改 PDF（含可填表单）。
3. 渲染页面图像校验文字、表格与表单元素。
4. 输出文件路径与校验结果。

## 触发条件

- 用户要求"导出 PDF、填写表单、合并/拆分 PDF、校验渲染"。
- 用户要求从 PDF 提取文字或表格。

## 权限

- `files:read` / `files:write`：仅工作区内的 PDF 文件。
