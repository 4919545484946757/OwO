# QQ 发送文件

用途：按联系人名称搜索并进入会话，附加指定文件后发送。

## 流程

1. 在 QQ 主窗口搜索联系人（变量 `{contact}`）。
2. 进入会话。
3. 打开发送文件入口，选择文件（变量 `{file}`）。
4. 确认发送（“消息出现”回读验证需 QQ 无障碍适配，v1 占位，执行后人工确认）。

## 变量

- `contact`：联系人名称
- `file`：待发送文件路径

## 安全

- 目标应用白名单：qq；消息内容默认掩码。
- 敏感面（密码/支付/验证码）不执行；发送动作需预览 + 审批。
