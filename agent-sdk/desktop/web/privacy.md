# 隐私声明（本地优先）

最后更新：2026-08-17（R10 发布工程骨架）

OwO Agent 是**本地优先**的智能体：默认全部数据留在本机，数据出境必须显式开启。

## 数据字典

| 数据类别 | 存储位置 | 内容 | 出境 | 保留期 |
|---|---|---|---|---|
| 会话与消息 | `<data>/index.db` | 对话历史、工具调用、快照 | 仅模型调用时经云端（见下） | 用户删除/清空前永久保留 |
| 审计日志 | `<data>/index.db` | 权限决策、工具调用记录、用量 | 否 | 同上 |
| 情景记忆 | `<data>/memory.jsonl` | 观察摘要（窗口标题/OCR 文本摘要） | 否 | 同上 |
| 技能包 | `<data>/skills/`、`<workspace>/skills/` | SKILL.md、流程技能图 | 仅主动导出/分享 | 用户删除前保留 |
| 笔记 | `<data>/notes/` | 笔记文档与块 | 否 | 同上 |
| 模型用量 | 进程内 + 用量记录 | token 计数、成本估算 | 否 | 随记录上限轮转 |
| trace 轨迹 | `<data>/traces/` | 回合元数据（时长/工具/用量） | 否 | 轮转 |

## 数据出境（必须显式开启）

- 模型调用：设置页"云端模型"开关或 `OWO_CLOUD_ENABLED`。开启后，**会话消息内容**会发送到模型端点（默认 DeepSeek 兼容端点；`OPENAI_BASE_URL` 可指向任意 OpenAI 兼容端点，包括本地 Ollama）。
- 关闭状态：拒绝一切云端模型调用（本地端点豁免），消息不出本机。
- 语音/OCR：可选云通道需独立凭据（`PADDLE_OCR_TOKEN` 等），同样受 egress 开关约束。

## 一键关闭

- **云端模型**：设置页"云端模型（数据出境）"开关 → 关；或 `OWO_CLOUD_ENABLED=false` 重启。
- **遥测（可选，默认关）**：默认不收集任何遥测；开启后仅上报聚合指标（功能计数、错误码分布、性能分位），不含任何内容/消息文本。开关见设置页。
- **一键清空**：设置页"存储与恢复 → 一键清空数据"（二次确认 `CLEAR_ALL`）清除会话/审计/笔记/记忆/自动化。

## 数据删除

- 单会话：删除会话（`/session/{id}` delete 或 UI）。
- 全量：`/storage/clear`（二次确认）或删除 `<data>` 目录。
- 备份：`/storage/backup` 生成 zip（含明文数据，请妥善保管；或自行加密）。

## 模型文件与本地推理

本地 ONNX OCR / STT 模型文件仅用于本地推理，不上传；模型文件哈希见 release 产物 `sbom.json`。
