# 安全策略（Security Policy）

OwO Agent SDK 的安全边界、漏洞报告与支持承诺（R10 发布工程骨架）。

## 支持版本

| 版本线 | 安全修复支持 |
|---|---|
| v0.7（当前） | ✅ 主动维护（安全修复随 minor 发布） |
| v0.6 | ✅ 支持至 v0.8 发布（弃用期 ≥2 个 minor） |
| 更早版本 | ❌ 不提供安全修复（请升级） |

## 报告漏洞

- 渠道：GitHub Issues（标记 `security`）或直接联系维护者（见仓库 README）。
- 响应承诺：48 小时内确认；高危问题 7 天内出修复版本；中低危随最近一次 minor 修复。
- 请勿在公开渠道披露 0-day 细节，先报告再发布。

## 安全边界（设计承诺）

- **权限默认 deny**：写/执行/注入类工具必须审批（`deny/ask/allow` 三级）。
- **模型凭据**：只经环境变量（`OPENAI_API_KEY` 等）或凭据库，禁止写入代码/配置/仓库。
- **数据出境开关**：`OWO_CLOUD_ENABLED=false` 时拒绝一切云端模型调用（本地端点豁免）。
- **存储加密**：Windows DPAPI 保护 DEK；数据加密统一使用 **v4 信封（AES-256-GCM，随机 nonce，AEAD 常量时间认证）**，所有新写入只允许 v4；v1/v2/v3 信封（DPAPI 自管理 / XOR 派生流 / XOR+HMAC）仅保留**只读迁移兼容，不再生成**，迁移需重新落盘为 v4；非 Windows 显式不可用、不静默降级。
- **插件供应链**：签名校验 + 静态扫描 + 吊销列表；吊销后拒绝加载。
- **网络 egress 边界**：插件/MCP `network_allowlist` 白名单，越界请求拒绝并审计。

## 漏洞等级参考

| 等级 | 示例 | 响应 |
|---|---|---|
| 严重 | 任意代码执行、凭据泄露、存储解密 | 7 天内修复 |
| 高 | 权限绕过、沙箱逃逸、审计链伪造 | 14 天内修复 |
| 中 | 信息泄露（非凭据）、DoS | 随最近 minor 修复 |
| 低 | 日志噪音、样式问题 | 随最近 minor 修复 |
