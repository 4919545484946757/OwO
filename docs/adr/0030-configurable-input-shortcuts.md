# ADR 0030：可配置输入模式快捷键与长拼音输入

- 状态：P3 后体验优化已采用
- 日期：2026-08-03

## 决策

1. 配置 Schema 升级到 v2，增加纠错切换、中英文切换、拼音原样上屏三组“启用状态 + 规范快捷键”字段，并兼容读取 v1。
2. 默认 `Alt` 切换当前 TSF 实例的拼音纠错状态；默认 `Ctrl+Space` 切换中英文。切入英文模式前必须先把候选框中尚未上屏的原始字符原样提交，提交成功后立即隐藏候选窗；英文模式的普通字符不进入 TSF 组合缓冲并由目标应用直接接收。默认 `Enter` 直接提交组合栏 ASCII 拼音。
3. TSF 在按键边界以 500 ms 节流热加载配置。普通 Ctrl/Alt/Win 字母组合不再进入拼音缓冲；快捷键只在精确的按键按下事件触发，按键松开事件始终交还宿主。设置中心等待组合键主键并剥离 Windows CRLF，后端拒绝单独 `Ctrl`、`Shift` 或无主键的多修饰键，避免吞掉复制、粘贴等宿主快捷键。
4. 内部候选协议升级到 v7，在候选请求中携带 `correction_enabled`。Core 只在启用时生成单次编辑纠错路径；不完整拼音和缩写候选不受影响。
5. TSF 组合输入上限明确为 256 个 ASCII 字符，纠错搜索上限由 32 增至 128 字节，协议允许最多 256 个源音节。超限按键被安全截获但不继续增长组合缓冲。

## 结果与边界

设置中心可以捕获单键或组合键、独立关闭每项快捷键，并在保存前与配置后端双重检查冲突。快捷键状态对现有文本进程热加载，但中英文与纠错的当前开关状态属于进程内会话，不跨进程持久化。协议 v7 的 Core 与 TSF 必须成套部署。
