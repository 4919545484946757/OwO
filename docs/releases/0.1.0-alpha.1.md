# OwO Input Method 0.1.0-alpha.1

- 状态：首个 Windows 11 x64 Alpha 发行版
- 日期：2026-08-09
- 许可证：OwO GPL-3.0-only；libime/Fcitx5Utils LGPL-2.1-or-later

## 范围

本版冻结 P1～P3 输入主链路和后续输入体验优化，P4 首批官方插件暂缓。发行物包含：

- Windows TSF 输入法与 Direct2D/DirectWrite 候选窗口；
- Core Service、完整拼音词库、用户词频学习；
- libime `zh_CN.lm` 本地中文上下文排序及不可用降级；
- WinUI 3 自包含设置中心；
- 当前用户范围的一键安装、启动和卸载脚本；首次注册/注销 TSF 时请求 UAC 授权；
- 第三方许可证、逐文件 SHA-256 清单和对应源码包。

## 本次发行前修复

候选请求刷新期间不再清空已确认的拼音分割预览。新字母或退格会在上一分割快照上更新，
直到新分割与新候选同时替换，避免预览短暂退回未分割拼音后再次分割造成的闪烁。

保护“完整多字母音节 + 后续音节 + 不完整尾字母”的源拼音分割，不再让纠错或缩写候选路径
改写预览。例如 `xingb` 稳定显示为 `xing'b`，`xingbaf` 稳定显示为 `xing'ba'f`；
同类 `bingb`、`lingm`、`zhengcanf` 输入一并覆盖。

修复运行中切换纠错开关后的分割状态：关闭纠错会立即丢弃旧的纠错预览，并严格按源输入
重新解析；含显式分隔符的无效片段（如 `quan'loi`）保持为 `quan'loi`，不再退化为
`q'u'a'n'l'o'i` 或继续显示切换前的分割。

OwO 在新宿主进程中激活时默认进入中文模式。TSF 原生组件改为静态链接 MSVC 运行库，
避免被 QQ 等宿主程序目录中的旧版 `MSVCP140.dll`/`VCRUNTIME140.dll` 替换，降低进程内
输入法组件与宿主私有运行库冲突导致崩溃的风险。

## 已知限制

- 发行 ZIP 尚未进行商业代码签名，Windows 可能显示来源警告。
- 首版只支持 Windows 11 x64；其他系统和架构后续适配。
- 安装器为当前用户 PowerShell 引导脚本；MSIX/WiX、签名和自动更新留待后续发行工程阶段。
- P4 官方插件及高权限第三方插件不属于本版验收范围。
