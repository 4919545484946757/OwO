# OwO Input Method 0.1.0-alpha.2

- 状态：Windows 11 x64 Alpha 预览版
- 许可证：OwO GPL-3.0-only；libime/Fcitx5Utils LGPL-2.1-or-later

## 重点变化

- 优化完整、不完整、缩写和纠错拼音的分割与候选生成。
- 引入词典感知的补全路径排序、真实中文上下文排序和可调词频学习。
- 完善候选窗口的分页、展开、滚轮、鼠标选择和拼音光标操作。
- 设置中心改为多页面布局，支持每项快捷键绑定多组组合键。
- 插件支持 `.owopkg`、ZIP 和文件夹，并保留高权限插件的单独风险授权。
- 改进安装、启动、设置中心和卸载流程，新增 Setup 可执行安装程序。

## 已知限制

- 当前仅正式支持 Windows 11 x64。
- Alpha 构建尚未进行商业代码签名。
- 智能排序依赖随包提供的本地 libime 模型；初始化失败时自动降级到基础候选。
