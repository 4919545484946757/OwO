# 插件权限与包格式草案

- 包扩展名为 `.owopkg`，采用 ADR 0008 定义的受限 ZIP 兼容容器、规范化清单与 Windows 发布者信任链。
- 发布者信任按 ADR 0019 完全离线且失败封闭：禁止 AIA/URL 链下载，只使用本地存储、CMS 内嵌证书和缓存撤销状态，并启用 Windows 强签名策略。P3C 不使用时间戳为过期证书降级。
- P3C 的受信安装仍是默认通道。P4 按 ADR 0022 增加第三方/未验证高风险通道：必须先预检信任、权限与清单摘要，再经过风险/免责勾选和第二次逐包授权；安装后保持停用，且不得显示为可信发布者。
- `runtime=process` 为 MVP 首选；不可信插件不得进入 TSF 或 Core Service 地址空间。
- 权限逐项声明且默认拒绝；权限升级必须重新确认。
- 授权记录按 ADR 0011 绑定精确插件版本、包清单摘要和发布者证书；每次敏感操作仍须核对当前 manifest，旧授权不得跨绑定继承。
- 安装记录 schema 2 同时固化发布者信任层级；旧 schema 1 记录只兼容为可信发布者。授权记录中的信任层级必须与安装记录一致，防止第三方或未验证版本在授权失败、撤销或迁移时被误标为可信。
- 授权记录按版本原子写入独立目录；缺失、损坏、schema 未知或与安装记录不一致时一律视为零授权。
- 网络默认关闭，文件默认仅允许插件自己的数据目录。
- Windows 11 普通进程插件按 ADR 0012 使用每插件零能力 AppContainer；网络禁用由令牌能力边界强制。只有声明并完整获授 `system.full_trust` 的精确版本可按 ADR 0022 使用当前用户普通令牌，且必须明确告知该模式没有逐项 OS 隔离。
- P4 权限目录增加网络、任意文件系统、外部进程、屏幕、麦克风、UI 覆盖、桌宠以及字典/主题/材质安装。需要普通 Win32 令牌的能力必须同时声明 `system.full_trust`；全信任不包含管理员提权或 UAC 绕过。
- 插件进程以不继承句柄的挂起状态创建，加入“关闭即终止、受限进程数与内存、未处理异常终止”的 Job 后才可恢复。AppContainer 为最多一个进程/128 MiB；全信任默认为最多一个进程/512 MiB，只有声明并获授 `process.launch` 时上限放宽到 8 个进程。
- PluginHost 管道按 ADR 0013 创建在目标 AppContainer 的会话命名对象空间，使用 128 位随机名、首实例/单实例、显式最小 DACL、有限时 overlapped I/O，并在首帧后精确核对客户端 `TokenAppContainerSid`。
- 启动时按 ADR 0014 重验活动版本绑定；安装树只读执行、数据树专属可写，环境块仅含显式 Windows 白名单和插件数据路径。握手、关停或进程退出异常时关闭整个 Job，不允许回退到普通进程。
- 调用按 ADR 0015 固定为单插件最多一个在途请求，只接受版本化服务；敏感调用必须同时满足用户动作标记、manifest 声明、活动版本绑定和精确授权记录。合作取消宽限 500 ms，超时、断线、协议乱序或拒绝取消均终止整个 Job。
- 管理面按 ADR 0016 以活动记录作为唯一启用状态；停用绑定预期版本并在独占句柄上重验后删除。恢复清理必须精确匹配两次新扫描，拒绝重解析点；未激活版本不自动删除，不安全条目永远只报告。
- 卸载按 ADR 0018 只接受精确未激活版本，并与安装、切换、停用和恢复清理跨进程串行化。安装目录先原子移入可审计墓碑，再删除精确版本记录与授权；最后版本同时删除确定性 AppContainer profile，`data/<plugin-id>` 始终保留。
- Core 调度按 ADR 0017 固定在单独工作线程和 32 项有界队列；TSF 来源无条件拒绝，只有内部可信用户动作来源可携带敏感权限。默认审计不记录调用负载、输入上下文或返回正文，活动绑定变化立即关闭旧插件 Job。
- ADR 0020 明确不在 P3C 暴露外部插件调用入口；候选 IPC、命令行和设置中心都不能提交 `trusted_user_action`。生产执行器保持空闲，首批插件的认证用户动作入口在 P4 单独设计。
- 受信安装入口继续按 ADR 0021 调用 `install`。P4 高风险入口按 ADR 0022 固定为“`inspect-install` → 双重知情确认 → 摘要绑定的 `install-risk`”；两个入口都只调用高层事务，不暴露低层暂存发布 API。
- 包安装必须防路径穿越、大小炸弹、重复 ID 和清单欺骗。
- 更新采用暂存、完整性验证、原子切换和可回滚流程。

容器与信任决策见 ADR 0008，版本化存储见 ADR 0010，PluginHost 内部契约和授权格式见 ADR 0011，Windows 进程沙箱见 ADR 0012，AppContainer 本地管道见 ADR 0013，已安装入口生命周期见 ADR 0014，调用控制面见 ADR 0015，显式管理与恢复见 ADR 0016，Core 非 TSF 调度见 ADR 0017，精确卸载见 ADR 0018，离线信任策略见 ADR 0019，外部调用边界见 ADR 0020，用户签名包安装入口见 ADR 0021，高风险知情安装与全信任边界见 ADR 0022。自动更新源仍未冻结。
